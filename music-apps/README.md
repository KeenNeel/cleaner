# 音楽アプリ一覧を作成

PC のデスクトップと C ドライブから、音楽生成 AI・歌声合成・DAW・音源分離・プラグインなどを探し、
デスクトップに **`音楽アプリ一覧.html`** を 1 ファイルで作るツールです。

## 使い方
1. **`音楽アプリ一覧を作成.bat`** をデスクトップなど好きな場所に置く (このファイル 1 つだけで動きます)
2. ダブルクリックする
3. 数分待つと、デスクトップに `音楽アプリ一覧.html` ができ、ブラウザで開きます

- Python などのインストールは不要です (Windows に最初から入っている PowerShell で動きます)。
- ファイルやレジストリを読むだけで、何も変更・削除しません。
- 「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください。

## HTML に載る内容
アプリ名、カテゴリ、用途、公式ページの URL、容量、起動方法、起動ファイル、インストール先、簡単な利用方法、
ショートカット、実行環境 (Python の venv / 同梱版、Node.js、Electron、ネイティブ 64bit など・GPU の使用)、
フォルダを移動しても起動できるか (○ / △ / × と理由)。VST / VST3 / CLAP / AAX プラグインは別表。絞り込み・並べ替えができます。

## 見つける範囲
- インストール済みソフト (レジストリ)、デスクトップとスタートメニューのショートカット
- Program Files・`%LOCALAPPDATA%\Programs` (2 階層)
- C:\ 直下・ユーザーフォルダ・デスクトップ (3 階層)。既知のアプリ名のほか、フォルダ名に Lyrics / Chord / Tape /
  Music / Vocal などを含み、起動ファイル (.exe / .bat) や requirements.txt・package.json があるフォルダも載せる
- VST / VST3 / CLAP / AAX プラグインフォルダ
- インターネットショートカット (.url) とブラウザの「アプリ」ショートカット: デスクトップ (5 階層)・ユーザーフォルダ・
  C:\ (4 階層)・お気に入り。既知の音楽系サービスか、URL・名前・置き場所のフォルダ名 (music_ai など)・
  リンク先ページのタイトルと説明から音楽系かどうかを判定する (ページの読み込みは最大 150 件、1 件 8 秒まで)

## 説明の出どころ
- 既知のアプリ・Web サービス: `src/details_apps.py` と `src/details_web.py` (概要・主な機能・使い方を箇条書きで記載)
- それ以外: フォルダ内の README の「Features / 機能」「Usage / 使い方 / Install」の項目、package.json の scripts、
  pyproject.toml の description、設定ファイルのポート番号から自動で作る
- HTML の「調査の依頼」ボタンで、正体が分からないものの一覧をコピーできる (開発者に送るとカタログに追加できる)

## 開発者向け
`.bat` は生成物です。`src/` を編集したら次を実行して作り直してください。

```
python music-apps/build.py
```

- `src/scan.ps1`: スキャン処理 (PowerShell 5.1)。結果を JSON にして HTML に埋め込む
- `src/report.html`: 表示用テンプレート (JSON を JavaScript で描画)
- `src/catalog.json`: 既知アプリのカタログ (用途・公式 URL・起動ファイル名・利用方法)
