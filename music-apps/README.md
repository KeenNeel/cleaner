# 音楽アプリ一覧を作成

PC のデスクトップと C ドライブから、音楽生成 AI・歌声合成・DAW・音源分離・プラグインなどを探し、
デスクトップに **`音楽アプリ一覧.html`** を 1 ファイルで作るツールです。

## 使い方
1. **`音楽アプリ一覧を作成.bat`** をデスクトップなど好きな場所に置く (このファイル 1 つだけで動きます)
2. ダブルクリックする
3. 数分待つと、デスクトップに `音楽アプリ一覧.html` ができ、ブラウザで開きます

- Python などのインストールは不要です (Windows に最初から入っている PowerShell で動きます)。
- ファイルやレジストリを読むだけで、何も変更・削除しません。
- 「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください。

## HTML に載る内容
アプリ名、カテゴリ、用途、公式ページの URL、容量、起動方法、起動ファイル、インストール先、簡単な利用方法、
ショートカット。VST / VST3 / CLAP / AAX プラグインは別表。絞り込み・並べ替えができます。

## 開発者向け
`.bat` は生成物です。`src/` を編集したら次を実行して作り直してください。

```
python music-apps/build.py
```

- `src/scan.ps1`: スキャン処理 (PowerShell 5.1)。結果を JSON にして HTML に埋め込む
- `src/report.html`: 表示用テンプレート (JSON を JavaScript で描画)
- `src/catalog.json`: 既知アプリのカタログ (用途・公式 URL・起動ファイル名・利用方法)
